## English

**CTO at [7Sense](https://7sen.se) · São Paulo, Brazil**

[7Sense](https://7sen.se) is a Brazilian startup connecting the physical world to the digital one for AI. The product is computer vision for safety compliance in construction and sanitation: a camera sees the operation, a server takes the feed, a model extracts the visual context.

Most of my time goes into balancing fast software development with AI and traditional quality and security practices.

### Personal projects

Most of them are Go. The Discord bot is TypeScript. Site: [ja1code.dev](https://ja1code.dev).

- **[quicrawl](https://github.com/ja1code/quicrawl)** — a Go crawler. One core backs both an HTTP server (Echo) and a CLI (Cobra). It returns a site's HTML, without running JavaScript, in a single response meant for LLMs. In progress.
- **[koolseal](https://github.com/ja1code/koolseal)** — a Go CLI for Kubernetes sealed secrets (kubeseal): create, update, and extract.
- **[vxer](https://github.com/ja1code/vxer)** — a TypeScript Discord bot (discord.js). It rewrites social video links into URLs the channel can play.

[7Sense](https://7sen.se) · [ja1code.dev](https://ja1code.dev) · [@ja1code](https://x.com/ja1code)
